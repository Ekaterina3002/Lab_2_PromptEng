## Что это

Многоагентный театр: четыре LLM-персонажа (Вера, Марк, Ника, Ада) разыгрывают пьесу об энергетической катастрофе 2042 года. Конфликт развивается из взаимодействия агентов, а не из заранее написанных реплик. Режиссёр-LLM планирует три действия, оркестратор выбирает следующего говорящего, отдельный планировщик решает, когда агенту нужен поиск по техническим документам, сценограф добавляет ремарки, Silero TTS озвучивает пьесу.

**Технологии:** Qwen3-0.6B (локально, для Ады), YandexGPT 5.1 (облако, для остальных), Silero TTS, Python-оркестратор.

## Артефакты

| Файл | Что внутри |
|------|------------|
| `LLM_Theatre.ipynb` | Весь код: генерация, оркестрация, сценограф, TTS |
| `play_plan.json` | Макроплан из 3 действий (9 событий) |
| `full_play.json` | 44 элемента: 31 реплика + 13 сценических |
| `staged_play_v2.json` / `.txt` | Пьеса с ремарками |
| `tool_log.json` | 31 запись о файловом поиске |
| `city_documents/` | 4 синтетических технических документа |
| `last_protocol_audio.wav` | Аудиоспектакль (Silero TTS) |
| `.env.sample` | Шаблон для ключей (без секретов) |

## Результаты (кратко)

- 3 действия, 9 событий, 31 реплика, 31 вызов поиска.
- **Ада:** 5 из 7 реплик уникальны (71%) после правок — было 3 из 8 (37%).
- **Финал:** Марк принимает конкретное решение («Решение принято: …») с ценой и защитными мерами.
- **Сценограф:** 31 из 31 реплик сохранены без изменений.
